<template row(item)></template>                   The parameter 'item' of template "row" needs a type or a default value, e.g. item: string or item = ''
<template row() class="a"></template>             A <template> declares only its name and its parameters, e.g. <template row(item: Item)>: it renders nothing where it is declared, but where a @render calls it
@render title()                                   Argument of type 'string' is not assignable to parameter of type '__Template<unknown[]>'.
@render count('a')                                Argument of type 'string' is not assignable to parameter of type 'number'.
@render count()                                   Expected 1 arguments, but got 0.
<svg>@render row()</svg>                          Template "row" is declared among HTML elements, and its content cannot be rendered among SVG elements: declare it in the namespace it is rendered in
@render row(...pair())                            @render passes each argument to its parameter: spread the values in separate arguments, e.g. @render row(pair()[0], pair()[1])
<my-list *when><template row()> …                 <my-list> cannot receive the template "row" as content: a structural directive is applied to it, whose content is a scope of its own. Apply the directive to an element wrapping it
<template><b>{ name() }</b></template>            The content of a <template> is static HTML, which the code using the template clones: it cannot interpolate values, render blocks or declare templates. Declare a template with <template name(…)> and render it with @render to bind values
<template><b (click)="go()"></b></template>       <b> is in the content of a <template>, static HTML which the code using the template clones: it takes only static attributes
<template shadowrootmode="open"></template>       A <template> cannot declare a shadow root with "shadowrootmode": the server writes the shadow root of each component
