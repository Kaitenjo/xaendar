Tag <card> is not a valid custom element name. Custom element names must:
- contain a hyphen
- no spaces.
- start with a lowercase letter.
- not contain uppercase letters.
- not be a native HTML tag name.
- not contain the following chars: '@', '#', '$', '%', '&', '*', '!', '?', '/', '\', '|', "'", '"', '<', '>', '='

Tag <font-face> is a reserved tag name and cannot be used as a custom element name.
Reserved names are:
- annotation-xml
- color-profile
- font-face
- font-face-src
- font-face-uri
- font-face-format
- font-face-name
- missing-glyph
