Tag <card> is not a valid custom element name. Custom element names must:
- start with a lowercase ASCII letter.
- contain a hyphen.
- not contain uppercase ASCII letters, whitespace, or ASCII symbols other than '-', '.' and '_'.

Tag <font-face> is a reserved tag name and cannot be used as a custom element name.
Reserved names are:
- annotation-xml
- color-profile
- font-face
- font-face-src
- font-face-uri
- font-face-format
- font-face-name
- missing-glyph
