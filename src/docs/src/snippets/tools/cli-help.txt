$ xd --help
Usage: xd [options] [command]

Xaendar CLI

Options:
  -V, --version                 output the version number
  -h, --help                    display help for command

Commands:
  component|c [options] <name>  Generate a new component (creates <name>/ folder
                                with .ts, .html, .css, .spec.ts)
  new [options] <name>          Scaffold a new Xaendar project
  start|s                       Start the project
  build|b                       Build the project
  help [command]                display help for command
