Conditional directives

Directives can be applied by an {'@if'} or a {'@switch'} written inside a tag, like the other conditional bindings. The element stays; the directive is created when its branch is taken, and destroyed when it is left.

Custom directives

Remove the directive from the first paragraph: onDestroy runs, and the effects of the instance are disposed. Apply it again: a new instance is created, with its own onInit. Nothing survives between the two, so a directive applied conditionally should leave the element as it found it, as this one does with the background.

The second paragraph keeps its directive, and switches only the binding of its input. The instance stays the same, and its effect simply runs again with the new value.

Structural directives

The paragraph always has exIsEven, and exPositive only while the box is checked. The rule does not change: the element is rendered while every directive currently applied returns true. Check the box while n is negative and even: exPositive joins and the paragraph disappears; uncheck it and the paragraph comes back. Both directives are defined in Structural directives.

Edge cases

A custom directive can bind its inputs inside a condition, as the second paragraph above does. A structural directive cannot: apply the whole directive conditionally instead, one per branch.

The parentheses of a directive hold its inputs and listeners, and conditions over them, but no other directive.

API summary

Syntax inside a tagBehavior
{'@if (c) { @@dir(…) }'}A new instance each time the branch is taken; onDestroy when it is left.
{'@@dir(@if (c) { input="…" })'}Same instance; only the binding of the input changes.
{'@if (c) { *dir(…) }'}The directive joins or leaves the AND of the structural directives of the element.
{'*dir(@if (c) { input="…" })'}Not allowed.
