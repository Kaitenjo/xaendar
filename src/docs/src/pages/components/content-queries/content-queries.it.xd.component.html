Query sul contenuto

Una query sul contenuto trova elementi tra il contenuto proiettato nel componente, invece che nel suo template. È il modo in cui un componente lavora con figli che non renderizza: un gruppo di tab con i suoi pannelli, una lista con i suoi elementi, un form con i suoi campi. Come per le query sulla vista, il risultato è un signal che segue i cambiamenti del contenuto.

Interrogare il contenuto proiettato

{'@Query.content'} e {'@Query.content.all'} accettano gli stessi target delle query sulla vista, un selettore CSS o la classe di un componente, e cercano tra gli elementi assegnati agli slot del componente, insieme ai loro discendenti.

Il gruppo renderizza una tab per ogni pannello che trova, con l’etichetta che il pannello ha ricevuto dal padre, e dice a ogni pannello se è attivo tramite un signal del pannello: la query è tipizzata dalla classe, quindi il gruppo può raggiungere i membri pubblici delle istanze. Aggiungi un pannello: il padre lo renderizza dentro il gruppo, la query lo trova, e compare una nuova tab.

Quali slot, quali elementi

Per default una query sul contenuto cerca in tutti gli slot. slots la restringe a uno slot, o a una lista, dove la stringa vuota è lo slot di default; lightDom: true guarda invece tutti i figli dell’elemento, assegnati a uno slot o no. Le due opzioni non si possono combinare.

  • i risultati seguono gli slot nell’ordine del template, poi l’ordine di assegnazione: aside viene per primo nell’inspector, quindi B viene prima di A, anche se nel padre A viene per primo;
  • i discendenti contano: C sta dentro un div assegnato allo slot di default;
  • D non è assegnato a nessuno slot: lo trova solo lightDom, in ordine di documento;
  • E è il fallback di uno slot: appartiene all’inspector, e nessuna query sul contenuto lo trova.

Query senza decoratori

querySlot e querySlotAll sono le funzioni dietro i decoratori, come query e queryAll per le query sulla vista, con la stessa avvertenza nei binding degli attributi.

Casi limite

Il wrapper proietta il proprio slot nel contatore. La query del contatore non vede quello slot ma ciò che trasporta: gli elementi scritti nel template più esterno, poi l’elemento del wrapper. Gli slot annidati vengono appiattiti.

Il contenuto proiettato viene creato dal padre dopo che il componente ha renderizzato, quindi in afterRender una query sul contenuto è ancora vuota. Leggila in modo reattivo, in un computed o in un effect, come fa il gruppo di tab. Vedi i casi limite della Proiezione di contenuto. Una query sul contenuto si aggiorna quando vengono aggiunti o rimossi elementi, quando cambia il loro attributo slot e quando cambiano gli slot del componente. Il cambiamento di qualsiasi altro attributo, come una classe, non la aggiorna, come per le query sulla vista.

Riepilogo API

APIDescrizione
{'@Query.content(target, options?)'}Il primo elemento proiettato che corrisponde a target, oppure null.
{'@Query.content.all(target, options?)'}Tutti gli elementi proiettati che corrispondono a target.
{"{ slots: 'name' }"}, {"{ slots: ['', 'name'] }"}Solo gli slot indicati; '' è lo slot di default.
{'{ lightDom: true }'}Tutti i figli dell’elemento, assegnati a uno slot o no.
querySlot(this, target, options?), querySlotAll(…)Le stesse query, create in un campo.
