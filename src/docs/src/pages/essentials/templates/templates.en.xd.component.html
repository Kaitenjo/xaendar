Dynamic templates

A template is an HTML5 file with a few additions: interpolations, bindings, event listeners and control flow blocks. Expressions are written in TypeScript and can use every public member of the component by name.

The syntax at a glance

SyntaxMeaning
{'{ count() }'}Text interpolation: renders the value of the expression as text.
title="Hello"A static attribute, or a static string for an input of a component.
{'title="{ label() }"'}A binding: sets the attribute, or the input, to the value of the expression.
(click)="save()"An event listener calling a method of the component; $event is the event.
{'@if (cond) { … } @else { … }'}Renders a block conditionally.
{'@for (item of items(); track item.id) { … }'}Renders a block for each item.
{'@switch (value) { @case (1) { … } @default { … } }'}Renders the block of the matching case.

Expressions

Expressions refer to the members of the component by their bare name: write items(), not this.items(). They can use literals, operators, calls, ternaries, template literals, optional chaining and the usual browser globals (Math, JSON…), but no assignments, arrow functions or new: logic belongs to the class.

Signals are never unwrapped automatically: {'{ count }'} renders the signal function itself. Always call it: {'{ count() }'}.

Special characters

In the text of a template, {'\x7B'} always starts an interpolation, {'@'} always starts a control flow block and {'<'} always starts a tag. To write them as text, interpolate a string: {'{ \'@\' }'}. See Template syntax.
