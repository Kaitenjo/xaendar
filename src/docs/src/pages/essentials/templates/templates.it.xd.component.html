Template dinamici

Un template è un file HTML5 con qualche aggiunta: interpolazioni, binding, listener di eventi e blocchi di controllo di flusso. Le espressioni si scrivono in TypeScript e possono usare per nome ogni membro pubblico del componente.

La sintassi in sintesi

SintassiSignificato
{'{ count() }'}Interpolazione: renderizza il valore dell’espressione come testo.
title="Ciao"Un attributo statico, o una stringa statica per un input di un componente.
{'title="{ label() }"'}Un binding: imposta l’attributo, o l’input, al valore dell’espressione.
(click)="save()"Un listener di evento che chiama un metodo del componente; $event è l’evento.
{'@if (cond) { … } @else { … }'}Renderizza un blocco in modo condizionale.
{'@for (item of items(); track item.id) { … }'}Renderizza un blocco per ogni elemento.
{'@switch (valore) { @case (1) { … } @default { … } }'}Renderizza il blocco del caso corrispondente.

Espressioni

Le espressioni si riferiscono ai membri del componente con il loro nome semplice: scrivi items(), non this.items(). Possono usare letterali, operatori, chiamate, ternari, template literal, optional chaining e i soliti globali del browser (Math, JSON…), ma niente assegnamenti, arrow function o new: la logica sta nella classe.

I signal non vengono mai “scartati” automaticamente: {'{ count }'} renderizza la funzione del signal. Chiamalo sempre: {'{ count() }'}.

Caratteri speciali

Nel testo di un template, {'\x7B'} inizia sempre un’interpolazione, {'@'} inizia sempre un blocco di controllo di flusso e {'<'} inizia sempre un tag. Per scriverli come testo, interpola una stringa: {'{ \'@\' }'}. Vedi Sintassi dei template.
