Text interpolation

An expression in braces, in the middle of the text, becomes a text node showing its value. The compiler wires that node to the signals the expression reads: when one of them changes, the expression runs again and only that node is updated.

Interpolating values

Each line updates by itself when you press a button, the one calling a method included: in text, the compiler wraps the whole expression in an effect, so whatever it reads, directly or through a method, is tracked. Attributes follow a stricter rule, explained in Binding.

The expression is checked against the class of the component, like TypeScript code written outside of it: it can read the public members by name, without this, and the globals such as Math or JSON. What an expression may contain is listed in Expression syntax.

What a value becomes

The value is converted to a string, with two exceptions: null and undefined become empty text.

The last row is the most common mistake: a signal is a function, and without the call the text shows the function itself. Nothing reports it, since showing a function is valid.

Edge cases

{"{ first() } { last() }"} renders the two values without the space, because the compiler drops text made only of whitespace. Write {'{`${first()} ${last()}`}'}, or {"{' '}"} between them. See Template syntax.

The compiler ends the interpolation at the first closing brace it finds, even inside a string, and generates invalid code. The error comes from the JavaScript parser that reads the generated code, not from the template compiler, and the module of the template fails to load.

An unpaired opening brace makes the compiler look for its closing brace up to the end of the file. Braces in pairs are fine; for a single one use {"{'\\x7B'}"}.

An expression that starts with a backtick after the space following the brace is not parsed. Write the backtick right after the brace, as in the example.

A template literal inside the placeholder of another one is split in the wrong place. Build the inner string in a computed signal or a method.

{"{ { value } }"} compiles and renders nothing at all: the inner braces are not read as an object. To show an object, convert it, for example with JSON.stringify.
