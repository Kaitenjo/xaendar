Conditional bindings

{'@if'} and {'@switch'} can also appear inside a tag, among its attributes. There they decide which attributes, listeners, inputs and directives the element has: the element itself stays, and only its bindings are added and removed as the conditions change.

Attributes and listeners

Lock the task: the button gets disabled and a new title; unlock it and both are replaced by the attributes of the {'@else'} branch. Turn editing off: the listener is removed, and clicks are no longer counted. Pick a priority: data-priority is set, changed or removed, and the stylesheet does the rest. Boolean attributes such as disabled are the main use: they count by their presence, so they cannot be bound to false, as explained in Binding.

Conditions are reactive, like those of the blocks, and conditional bindings can be nested. A branch can hold the same things a tag can: static and bound attributes, listeners and directives. The directives applied conditionally have a page of their own: Conditional directives.

Inputs of components

On the tag of a component, a conditional binding sets an input while the condition holds. When it stops holding, the input goes back to its default value, not to the last value it received.

Edge cases

To restore the default when a conditional binding is removed, the compiler copies the default of the input, as it is written in the decorator, into the code of the template binding it. A default written as an identifier, or as any expression that depends on the file of the component, does not exist there, and the template of the parent stops rendering.

A required input bound conditionally must be bound in every branch, including an {'@else'} or a {'@default'}, or outside the condition.

The same attribute cannot be written both outside and inside a condition. Different branches of the same condition, instead, can bind it each in their own way.

API summary

Syntax inside a tagDescription
{'@if (condition) { name="value" }'}Attributes, listeners, inputs and directives present while the condition holds.
{'@else { … }'}The bindings used otherwise.
{"@switch (value) { @case ('a') { … } }"}Bindings chosen by value.
