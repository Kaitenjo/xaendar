Framework per Web Components

Web Component, compilati in aggiornamenti chirurgici del DOM

Xaendar estende HTML5 con un linguaggio di template dichiarativo. Il compilatore analizza ogni template e collega ogni elemento, attributo e nodo di testo direttamente ai signal che legge: niente virtual DOM, nessun re-render dei componenti — il cambio di un signal tocca solo i nodi che ne dipendono.

Perché Xaendar

Web Component nativi Ogni componente è un vero custom element con il proprio shadow root: usalo ovunque, con qualsiasi altro framework o senza.
Signal al centro Lo stato vive in signal basati sulla proposta TC39. I valori derivati sono lazy e in cache, gli effetti sono raggruppati.
Template compilati e tipizzati I template sono compilati in fase di build e verificati contro la classe del componente: gli errori fanno fallire la build.
Nessun virtual DOM Il codice generato collega ogni nodo del DOM ai signal che legge. Niente viene confrontato, niente viene ri-renderizzato.
Direttive Aggiungi comportamenti riutilizzabili a qualsiasi elemento con le direttive custom, o decidi se esiste con quelle strutturali.
Query reattive Interroga lo shadow DOM o il contenuto proiettato: i risultati sono signal che seguono ogni modifica del DOM.

Esplora la documentazione

Fondamenti → Componenti, signal e template in pochi minuti. Signal → signal, computed, effect, untracked e i loro casi limite. Componenti → Input, output, ciclo di vita, slot e query. Template → Interpolazione, binding, eventi e controllo di flusso. Direttive → Direttive custom, strutturali e condizionali. Riferimento → API, prontuario della sintassi, enciclopedia degli errori e problemi noti.
