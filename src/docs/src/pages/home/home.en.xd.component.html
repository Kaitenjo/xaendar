Web Components framework

Web Components, compiled to surgical DOM updates

Xaendar extends HTML5 with a declarative template language. The compiler analyses every template and wires each element, attribute and text node straight to the signals it reads: no virtual DOM, no component re-renders — a signal change touches only the nodes that depend on it.

Why Xaendar

Native Web Components Every component is a real custom element with its own shadow root: use it anywhere, with any other framework or none.
Signals at the core State lives in signals based on the TC39 proposal. Derived values are lazy and cached, effects are batched.
Compiled, type-checked templates Templates are compiled at build time and type-checked against the component class: mistakes fail the build.
No virtual DOM The generated code binds each DOM node to the signals it reads. Nothing is diffed, nothing is re-rendered.
Directives Attach reusable behavior to any element with custom directives, or decide whether it exists with structural ones.
Reactive queries Query the shadow DOM or the projected content: results are signals that follow every DOM change.
