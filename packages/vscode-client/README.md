# Xaendar for Visual Studio Code

Language support for [Xaendar](https://github.com/Kaitenjo/xaendar) templates, the declarative Web Components framework that extends HTML5.

## Features

- Syntax highlighting of the template language: control flow (`@if`, `@for`, …), bindings, events, interpolations and element refs.
- Completion and diagnostics, powered by the Xaendar language server.
- Auto-import of the components used in a template.
- Template formatting.

The extension activates on HTML and TypeScript files.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `xaendar.format.printWidth` | `120` | Width, in columns, a line of a template should stay within when it is formatted. |
