# @xaendar/common

Shared runtime utilities/models with no framework dependency (string/indent/tag utils, a `stack` model, the HTML serialization rules: escaping, void and raw text elements). No `@xaendar/*` dependencies. Used by `signals`, `core`, `compiler`, `ssr`, `ssr-compiler`, `build-tools`, `cli`.
